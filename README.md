# Bhargav Vekariya — Portfolio

Single-page portfolio for a Senior Shopify Developer. Plain HTML/CSS/JS, no build step.

## Files
- `index.html` — the whole site
- `assets/bhargav.jpg` — profile photo

## Publish on GitHub Pages
1. Create a new repository on GitHub. For the URL `https://<username>.github.io`, name the repo exactly `<username>.github.io`.
2. Upload `index.html`, `README.md` and the `assets` folder (keep the folder structure).
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. Your site will be live in a minute or two at the URL shown on that page.

## Editing
- **Projects:** edit the `projects` array near the bottom of `index.html` (name, tag, url).
- **Text:** search `index.html` for the section (About, Experience, Skills, Contact) and edit in place.
- **Photo:** replace `assets/bhargav.jpg` with a square image of the same name.
- **Colours:** change the variables at the top of the `<style>` block (`--accent` is the red).
